# Professional

N.B. for reasons of confidentiality, these projects won't be named.

## Distributed Virtual Filesystem

Built to solve the problem of how to take an existing PHP application (think WordPress) and bring it into the modern
serverless world. Providing automatic scaling for load management, true scale to 0 capability and reducing admin
overhead.

Built in Rust, leveraging several existing services in the AWS ecosystem. Features a novel transparent asynchronous
write buffer to tackle the performance challenges.

## Image Processing & Machine Learning Daemon

MacOS native, high performance & soft realtime data processing pipeline for RAW image formats & local machine learning (
before LLMs were cool) for objective feedback.

Cross-functional integration with ML models (conversion from AOT to soft-realtime) & the electron front end.

## Distributed CWMP/TR-069 server

Solving the problems of orchestration at scale for ISP's without the cost associated with the big name platforms.
Written in Golang leveraging RethinkDB w/ a Vue.js front end.

# Personal

## Inkwell

A structured writing tool, for writers and TTRPG Game Masters, built to solve the limitations of Fantasia Archive. Avoid
the costs and online only nature of WorldAnvil and the unstructured nature of Obsidian.md & Legend Keeper.

Built with Skeleton.dev, Tailwind CSS, Svelte, Rust, Tauri and SurrealDB.

## Quatschen

An alternate Quassel IRC client, build to solve my annoyances with the original. Expanded with smart notification
handling and WASM plugin support.

Built with Skeleton.dev, Tailwind CSS, Svelte, Rust.

## Workshop-Walker

A tool to solve the problem of "how do I know what steam workshop items depend on this". Built with Skeleton.dev,
Tailwind CSS, Svelte, Rust and SurrealDB.
